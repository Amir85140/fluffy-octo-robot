# CyberRange — фоновый тренажёр реальных кибератак

**Агент не имеет окон.** Оператор ставит его на машину сотрудника, агент встаёт в автостарт,
супервизор перезапускает его при любом падении, и он работает постоянно до команды `--uninstall`.
Сотрудник просто работает; атаки приходят системными уведомлениями и реальными действиями в песочнице.

## Запуск сервера (машина оператора)
```bash
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
